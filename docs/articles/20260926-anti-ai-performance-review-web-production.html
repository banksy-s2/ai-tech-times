VIVANT生成AI利用の裏で進む反AI人事考課の現実

日本のAI2026-09-26 17:06 更新 / 生成AI人事考課WEB制作
⚡ 3行まとめ
  • VIVANTでの生成AI利用が話題に
  • WEB制作会社で反AIの社員が低評価
  • 新たな給与体系への移行期に直面
テレビドラマでの生成AI利用が話題となる中、あるWEB制作会社の現場で反AIの姿勢をとる社員の評価を巡る動きが表面化しました。

テレビドラマ「VIVANT」で生成AIが使われていた件が一部で議論を呼んでいますが、実際のビジネス現場でも生成AIを巡る動きが出てきています。WEB制作会社のフロントエンドエンジニアチームで課長を務める人物によると、社内では反AIの姿勢をとる社員の処遇を巡る動きがあるということです。

現在、人事考課の時期を迎えており、他部署の反AIデザイナーに対して非常に低い評価がつけられそうな状況だと明かされています。ちょうど11月から新しい給与体系に変わるタイミングと重なっており、社内の評価基準や姿勢が問われる局面となっています。

生成AIの活用が進む業界の動向とともに、社内でのスタンスや評価がどのように影響していくのか、今後の展開に注目が集まっています。
