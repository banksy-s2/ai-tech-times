アップル増益、メモリ高騰に懸念なぜ

アップルが発表したことし6月までの3か月間の決算は、iPhoneの販売が好調で増益となりました。一方で、半導体メモリの価格高騰について懸念が示されています。

ニュースサイト「AI TECH TIMES」がお伝えします。アメリカのIT大手「アップル」のことし6月までの3か月間の決算が発表され、iPhoneの販売が好調だったことを受けて増益となりました。主力商品の売上が全体を牽引する結果となりました。

しかし、順調な業績の一方で、今後の懸念材料も浮上しています。決算に関連して、ティム・クックCEOは半導体メモリの価格高騰について言及しました。同氏はメモリの価格高騰を「100年に1度の異常事態」だと表現し、今後のコストや供給への影響を示唆しています。

好調なハードウェア販売を維持するアップルにとって、半導体メモリの調達環境の変化は無視できない課題です。今後の業績や製品価格への波及について、業界内外から高い関心が寄せられています。
