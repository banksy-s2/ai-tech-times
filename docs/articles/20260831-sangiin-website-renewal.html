参議院ホームページが17年ぶり刷新、30万未満の案件に

日本のAI2026-08-31 14:00 更新 / 参議院ホームページデザインリニューアル
⚡ 3行まとめ
  • 参議院ホームページが17年ぶりにリニューアル
  • AIで作ったかのような出来栄えに困惑の声
  • 当該案件の落札価格は30万円未満と判明
参議院のホームページがデザインリニューアルされましたが、その出来栄えを巡って困惑の声が上がっています。落札価格は30万円を切る案件でした。

参議院審議中継によると、参議院ホームページ（sangiin.go.jp）のデザインリニューアルが実施されました。平成21年以来となる17年ぶりのデザイン刷新となり、視認性や操作性を向上させ、利用者が目的の情報にたどり着きやすいホームページにしたとのことです。

また、リニューアルと併せて、国会議事堂内を360度の映像で体感できる「バーチャルツアー」なども公開されました。

しかし、刷新されたホームページのデザインに対しては「AIで丸ごと作ったか？」という出来栄えであるとして困惑する声が上がっています。さらに、このリニューアル案件の落札価格が30万円を切る価格であったことが注目を集めています。
