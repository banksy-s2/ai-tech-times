SamsungとSK Hynix、2028年までに月60万枚増産で中国との差がさらに広がる理由

日本のAI2026-09-07 18:00 更新 / 半導体SamsungSK Hynix
⚡ 3行まとめ
  • 韓国のメモリ生産が2028年までに月60万枚増加
  • 中国のCXMTも増産するが技術面等で差が開く見込み
  • 歩留まりの制約により実際の生産量で大きな差に
韓国銀行の報告によると、韓国の主要半導体企業が国内生産設備を大幅に増強することで、中国とのメモリ生産能力の格差がさらに拡大する見通しであることが分かりました。

AI TECH TIMES編集部が報じたところによると、韓国銀行の報告書によって、韓国のメモリ半導体産業における圧倒的な優位性が今後さらに広がる見通しであることが明らかになりました。背景には、韓国を代表する半導体メーカーであるSamsungとSK Hynixによる国内生産設備の積極的な増強があります。

韓国では2028年までに月60万枚規模でメモリの生産能力が増加する計画が進められています。これに対し、中国のメモリメーカーであるCXMTも月30万枚の増産を計画するなど、大規模な生産能力の拡大を試みています。しかし、中国側は歩留まりや技術面での様々な制約を抱えているのが現状です。

こうした技術的課題があるため、名目上の生産能力の数値以上に、実際の生産量においては韓国との間にさらに大きな差が開く可能性が高いと分析されています。韓国勢の堅実な設備投資と技術力が、世界のメモリ半導体市場における地位を揺るぎないものにしています。
